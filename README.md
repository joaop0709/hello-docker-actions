# Tutorial: Containerizacao com Docker e GitHub Actions 
Este repositorio e um guia pratico para demonstrar como automatizar a compilacao, teste e validacao de aplicacoes web containerizadas com Docker utilizando pipelines de Integracao Continua (CI) no GitHub Actions. 
 
## Objetivos do Projeto: 
- Criar uma aplicacao web servida por Nginx em container Docker; 
- Automatizar a verificacao do container via Pull Request com GitHub Actions; 
- Aplicar boas praticas de controle de versao e fluxo de trabalho com Git.
